**Task:** you are an AI agent generator and below is an agent specification. Generate an agent according to the specification. Consider that the agent's tools must be generated along with the agent code.
**Context:** An AI agent is an entity that uses LLM and tools to perform specific tasks autonomously.
**Output:** `agent.py`, `requirements.txt`, `tests.py`
**Interface contract with the benchmark:**

| Interface requirement | Fixed requirement |
| :---- | :---- |
| Model | GPT-4o |
| Framework | LangGraph |
| GenAI Tool | ChatOpenAI |
| Tools | Exactly two LangChain tools (`@tool`, `StructuredTool` or obtained from an MCP server via `langchain-mcp-adapters`), generated along with the agent and executed exclusively through their interface (`invoke`/`ainvoke`, directly or via `ToolNode`), never by directly calling the function that implements them. In this agent, both use `@tool`/`StructuredTool` with local implementation. `ChatOpenAI` is the model interface and not a LangChain tool. |
| Entrypoint | agent(...) |
| Output | state: dict containing the user profile (user_data), the current plan (fitness_plan), the feedback (feedback), the progress history (progress) and the exchanged messages (messages) |
